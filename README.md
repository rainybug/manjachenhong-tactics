# 만자천홍 전술판 v1.1.1

기존 v1.1에 **영역 선택·묶음 이동·정렬·회색 기본 색상·실험적인 역할 마크**를 추가한 버전입니다. 63명의 일본어 이름과 3부(5년 후) 얼굴 이미지 연동, 유닛/전술판 관리, 자유 배치, JSON 백업도 유지됩니다.

## 기존 v1.1 이용자는 먼저 읽어 주세요

1. **기존 v1.1 앱을 열고 `↓ 백업`으로 JSON 파일을 저장하세요.** v1.1.1에서는 별도의 브라우저 저장 키(`manjacheonhong-tactics-v1-1-1`)를 사용하므로 이전 브라우저 데이터는 자동 복사하지 않습니다. 원본 v1.1 데이터는 삭제되지 않습니다.
2. 새 v1.1.1 폴더의 `index.html`을 열고 **`↑ 복원` → v1.1 백업 JSON 선택**으로 이전 데이터를 가져오세요. 유닛 이름·병종·기존 색상·사진 업로드분·여러 전술판·배치 좌표가 유지됩니다. 새 역할 마크는 `마크 없음`, 역할 표시 설정은 OFF로 시작합니다.
3. **기존 초상화 파일이 있다면** v1.1 폴더의 `assets/portraits/` 내용 전체를 새 v1.1.1 폴더의 동일한 위치로 복사하세요. 기본 이미지들은 JSON 백업에 포함되지 않습니다.
4. 이전 데이터가 없고 새로 시작한다면, 기본 유닛 63명의 색상은 전부 **회색(미지정)** 입니다. 기존 5색은 그대로 선택할 수 있습니다. v1.1 백업의 색상은 자동으로 바뀌지 않습니다.

## v1.1.1 새 기능

### 영역 선택과 묶음 이동

- 화면 상단 `영역 선택` 버튼을 누르면 **선택 모드**에 들어갑니다. 일반 모드에서는 기존처럼 빈 공간을 드래그하면 화면이 이동합니다.
- 선택 모드에서는 빈 공간에서 사각형을 그리듯 드래그하여 **겹치는 유닛을 선택**합니다. 이 상태에서 **선택된 카드 하나를 드래그**하면 모든 선택 유닛이 상대 위치를 유지하며 함께 이동합니다.
- 선택 모드에서 카드를 짧게 누르면 단독 선택, `Shift+클릭`하면 선택 대상 추가·제외가 됩니다. `전체 선택`으로 메인 필드에 있는 유닛을 모두 선택할 수도 있습니다.
- 선택 모드가 활성화된 동안에는 카드를 짧게 눌러도 편집창이 열리지 않습니다. 이름·병종을 편집하려면 선택 모드를 끄세요.
- 모바일에서도 선택 모드를 켜고 드래그하면 영역 선택과 묶음 이동이 가능하며, 선택 도구는 좁은 화면에서 가로로 스크롤됩니다.

### 선택 유닛 정렬과 색상

- 2명 이상 선택한 후 `왼쪽 정렬` / `위쪽 정렬` / `가로 균등` / `세로 균등` / `격자 정렬`을 누르세요.
- 격자 정렬의 열 수는 2~5열을 지정할 수 있습니다. 선택하지 않은 유닛의 위치는 바뀌지 않습니다.
- 선택 색상을 고르고 `일괄 적용`하면 선택 유닛의 색을 한 번에 변경합니다. 유닛 색은 **모든 전술판에서 공유**됩니다.
- 이동·정렬·일괄 색상 변경은 `↶ 되돌리기` 또는 `Ctrl+Z`(Mac은 `Cmd+Z`)로 취소할 수 있습니다. 실행 취소 기록은 현재 열린 앱에서만 유지되며, 새로고침하면 초기화됩니다.

### 실험 기능: 역할 마크

- `역할 OFF`가 기본값이며, `역할 ON`으로 전환하면 지정한 역할 마크가 **카드 이름 오른쪽**에 표시됩니다. 직사각형 카드 폭 152px은 유지됩니다.
- 개별 카드 편집창에서 역할을 8가지 중 고를 수 있습니다: 근접·궁병·중갑/방어·비행·기병·마도·회복/지원·복합/특수. 기본은 `마크 없음`입니다.
- `병종으로 추천` 버튼은 병종 이름의 일본어 키워드에서 역할을 **제안**할 뿐이며, 언제든 사용자가 바꿀 수 있습니다. 병종에 따라 일치하지 않을 수 있습니다.

## 설치·얼굴 이미지 관리

- ZIP 파일 전체를 해제하고, `index.html`을 Chrome/Edge/Safari 등에서 엽니다.
- **이미지 원본 64장 중 2장만 ZIP에 포함**돼 있습니다. 처음 사용한다면 인터넷에 연결된 상태에서 폴더의 `사진받기-Windows.bat`을 실행해 나머지를 받아 두세요. macOS/Linux 사용자는 `python3 download_portraits.py`를 실행할 수 있습니다.
- v1.1에서 이미 사진을 내려받은 경우에는 `assets/portraits/` 폴더를 복사하는 것만으로 충분합니다. 앱은 온라인 이미지가 아닌 로컬 이미지를 참조합니다.
- 다운로드할 때 외부 이미지 서버의 제한으로 일부 파일이 실패할 수 있습니다. 이 경우 재시도하거나 유닛 편집창에서 사진을 수동으로 지정할 수 있습니다.

## 백업·호환성

- `↓ 백업`으로 **v1.1.1 JSON**을 다운로드할 수 있습니다. `↑ 복원`은 **v1.1과 v1.1.1 백업**을 받습니다. 복원 시 현재 v1.1.1 데이터 전체를 교체하므로, 필요한 경우 먼저 내보내세요.
- **v1.0 형식의 백업은 지원하지 않습니다.**
- 새 저장 키: `manjacheonhong-tactics-v1-1-1`. v1.1은 별도의 기존 키를 그대로 사용합니다. 브라우저 및 HTML 파일 주소에 따라 저장소가 분리될 수 있으므로 JSON 백업을 권장합니다.
- JSON 백업에는 **사용자가 교체한 이미지**만 포함됩니다. 기본 초상화 파일은 ZIP 폴더의 `assets/portraits/`에 보관하므로, 컴퓨터 이전 시 앱 폴더도 함께 복사하세요.
- 기본 플레이어블 후보 63명(일본어 이름), 병종 미지정, 최대 등록 90명, 전술판 1600×900/25명 카운터, 실제 배치 인원에 강제 제한 없음. 고정된 부대 그룹/부대명 기능은 아직 포함되지 않습니다.
